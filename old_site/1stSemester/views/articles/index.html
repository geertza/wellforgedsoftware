What is DNS?

In simple terms, the Domain Name System (DNS) is like the internet's phonebook, translating human-readable website names (like "google.com") into the numerical IP addresses (like "172.217.16.46") that computers use to call out to websites. When you type a website address into your browser, your computer looks up the phone number through a DNS server for the the IP address, which it then uses to dial to the server hosting the site. This system makes it easier for people to navigate the web without needing to remember complex strings of numbers.
